# Nasdaq Lens

面向纳斯达克股票样本的风险收益可视化与中文智能问数系统。

股票池现采用Nasdaq官网2026-11-02快照：100家公司、101个证券代码。2023—2025年行情已部分接入：**当前71/101个代码有数据，63个日期完整，49,228条日线；尚非完整覆盖**。不依赖大模型API，不提供实时行情。课程最终作品文档与PPT将在系统验收后整理。

## Windows启动

在PowerShell进入项目目录，使用Python 3.12：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
py -m pip install -r requirements-dev.txt
py scripts/download_data.py
py -m streamlit run app.py
```

如果本机的py启动器未识别已激活环境，使用`.\.venv\Scripts\python.exe`执行同一命令。无法运行激活脚本时也可以直接使用该解释器，无需改变系统执行策略。

下载日期默认2023-01-01至2026-01-01（结束日不包含）。当前下载源为东方财富公开接口，原始价格与前复权价格分别采集，留存身份、日期、请求与文件哈希验证；首次下载需要联网，后续页面使用本地缓存。默认覆盖门槛95%，不足时保留旧研究缓存，不能把失败当完整下载。

更新官方名单：`py scripts/update_universe.py`。名单来源PDF保存在`.cache/universe/`，可用`--source-pdf <path>`重新解析已下载的文件；名单快照时间与下载时间分别记录。

本机网络间歇中断，当前明确以部分研究模式发布已有数据：`py scripts/download_data.py --cache-only --min-coverage .7`。这是显式接纳部分覆盖，不表示达成默认95%门槛。界面持续披露缺失数量，数据页列出全部代码覆盖；之后可重新执行默认下载命令断点补采。

如果Yahoo在本地网络限流或不可达，可先使用官方公开历史示例体验：

```powershell
py scripts/import_demo.py
py -m streamlit run app.py
```

该模式采用Plotly示例仓库中的2015—2017年5只股票数据，含非指数样本和历史退市代码，界面会明确标识，**不得作为2023—2025年纳斯达克100研究结论**。模式不会自动用历史数据覆盖研究缓存。

2026-11-15本地验证：Yahoo不可达后改用东方财富，部分行情取得；历史示例保留为独立模式；40项核心、采集校验、问数及页面集成测试通过。精确环境版本见requirements-lock.txt（Python 3.12，Windows开发环境）。

## 使用

- 侧栏选择股票池、日期及页面。
- 概览比较累计收益与行业样本表现；个股页面查看K线、月收益、波动与回撤。
- 聚类页面调整K并查看轮廓系数；问数页面输入“2025年最大回撤最小的前5只股票”等问题。
- 数据页面查看下载来源、覆盖范围与清洗记录，导出指标。

问数第二版支持“与苹果近一年相关性最高的前5只股票”“比较苹果和微软近三个月的波动率”等请求。相对时间**以侧栏所选结束日为基准**，不以当天日期为基准。解析条件、实际计算窗口、样本排除和排名依据均可查看；点击下载后保留结果，修改研究范围后旧结果自动清除。

一次指定一个时间范围和一个分析指标；市值、财务指标、预测以及多目标排序尚不支持。相关性矩阵与月度热力图最多20只，趋势比较最多10只。具体设计与验收见[第三阶段记录](docs/stage-3.md)。
