# 智能问数与可解释结果

## 本轮交付
- 新增独立query_engine模块，解析、计算与界面分离；统一日期覆盖、样本排除和结果输出。
- 支持近一年、近三个月、近30天、今年、去年、本月和上月。相对时间锚定侧栏所选结束日，页面明确显示基准，不使用操作系统当天日期。
- 支持与单只参考股票的相关性排名，排除自身，逐对检查至少20组有效日收益，并输出成对观测数。
- 波动率趋势实际计算20日滚动年化波动，回撤趋势实际计算窗口内回撤，不再把这些问法都展示成累计收益。
- 每次结果显示程序计算的解释、排除说明和可展开的解析条件；CSV内容与图表一致。
- 表单提交与结果状态分开，下载或重绘后保留结果；股票范围、日期、数据文件或模式变化后清除旧结果。
- 不支持的财务指标、预测、混合时间范围和多指标排序明确拒绝，不猜测查询含义。

## 验证
40项自动测试通过，包括时间边界、排名方向、相关性自相关排除、样本数量、波动计算、缺失历史、英文名与大小写代码以及表单状态。
浏览器使用本地真实研究数据验证相关性排名、滚动波动率、回撤排名及下载后保留结果。
