# 需求与第一版边界

课程：深圳技术大学 数据可视化技术；作者：李晴，202400702062。

## 使用场景
用户选择股票和日期，比较收益、波动和回撤，通过自然语言查询排名或趋势，并探索风险收益聚类。系统解释计算口径，结果可以下载，数据访问失败时不得用模拟数据冒充真实行情。

## 本次迭代
- 10只股票开发样本，2023—2025年日线；明确标识非完整指数。
- 5个页面：概览、个股、聚类、问数、数据来源。
- 超过10种图表，股票与日期统一筛选。
- StandardScaler + K-means，固定随机种子，轮廓系数比较K值。
- 中文受控问数，展示解析条件；超范围和不支持问题明确报错。
- 本地缓存、数据来源清单、清洗记录、校验摘要。

## 验收
1. 下载后可断网启动并浏览所有页面。
2. 已知价格路径的收益及最大回撤与手算一致。
3. 缺失数据不填成零收益，排名在同一共同时间窗口计算。
4. 回撤最小排序为损失幅度最小，而非负数数值最小。
5. 中文股票别名、年份、排名数量能够解析；不支持问题不猜测。
6. 聚类可复现且样本不足时有提示。

## 后续迭代
核验并导入带来源日期的完整成分股快照；处理股份类别、代码变更和短历史样本；增强问数语义校验；完善课程作品报告和汇报PPT。大模型API为可选增强，不作为基础运行前提。

## 架构
CSV原始行情 → schema校验与清洗 → 统一时间窗口 → 指标计算 → Plotly可视化/聚类。
中文问题 → 白名单规则解析 → 参数检查 → 同一指标计算模块 → 图表及CSV。
Streamlit只承担交互与呈现，计算和问数逻辑分别位于nasdaq模块，下载脚本可独立运行。
