# 第一版开发记录

## 需求与设计
从课程金融信息服务方向提炼：自然语言分析、至少10张图表、机器学习建模、数据来源与程序可复现。采用Streamlit降低初版开发成本，将数据、计算、解析和界面拆分。

## 实现
行情下载与质量检查，复权指标，行业样本比较，个股图表，K-means与轮廓系数，中文白名单问数及CSV导出。

## 已验证
- 13项测试覆盖已知价格路径、清洗、缺失值、未知代码、回撤排名方向、聚类可复现、五页面集成、成功问数、拒绝不支持问题、无数据入口。
- 独立Headless Edge浏览器逐页导航，完成页面截图，无页面异常。
- Yahoo本地及沙箱外下载均遇限流；没有生成模拟研究数据。
- Plotly官方公开历史示例导入3634条有效日线；界面明确区分演示与研究模式。
