# 数据来源与限制

当前行情提供方：东方财富公开美股日线接口。原先Yahoo/yfinance路径在本地不可达，现不作为默认采集源。
接口结构参考AKShare项目的stock_us_hist_em实现：https://github.com/akfamily/akshare/blob/main/akshare/stock/quote/stock_hist_em.py
采集使用公开接口及本地原始响应缓存，不需要账户密钥。
指数定义参考：https://indexes.nasdaq.com/Index/Overview/NDX

data/universe.csv来自Nasdaq官方2026-11-02 PDF快照，共101个证券代码（Alphabet包含A、C两类股份），对应100家公司；来源、下载时间与源文件SHA256记录于data/universe_manifest.json。行业为项目自定义粗分组，不是官方GICS/ICB。不能据此重建2023—2025年的历史成分指数。

官方快照来源：https://www.nasdaq.com/docs/global-indexes/NDX

当前已有71个代码、49,228条有效日线，63个覆盖2023—2025年全部已观测交易日。剩余代码及短历史清单见data/quality_summary.json。该文件只包含覆盖统计，不含逐日原始行情。缺失可能来自网络、供应商覆盖、上市时间或交易所/代码变更，未核验前不将某一种原因写成事实。

下载脚本记录UTC获取时间、请求范围、实际成功代码、失败代码、原始价格及复权口径、清洗数量和文件SHA256。下载结束日不包含在请求范围内。下载失败不得生成随机价格；完全失败保留旧缓存；部分失败在清单中披露。

fqt=0原始OHLC用于K线；fqt=1前复权收盘价映射至adj_close，用于调整后价格收益、回撤和聚类。前复权结果随采集时点可能改变，不能未经核验就声称是分红再投资总收益。原始与复权交易日期必须一致，代码身份必须匹配，发现异常不做静默替代。成交量按供应商股数记录。滚动年化波动以252交易日为约定。月收益采用窗口内月末价格，首月缺少上月末基期，因此不计算。

完整样本筛选以本地全体已观测交易日期为参考日历，不是交易所官方日历；可以发现某只股票相对其他股票缺少记录，但不能发现全体股票同日同时缺失。默认启用该筛选，避免短历史股票把全体比较窗口压缩至几天。

缓存行情和环境密钥不纳入Git提交，使用者应遵守数据提供方条款，实际提交或公开数据前检查授权。测试中的人工价格路径仅用于验证公式，不会展示成实际行情。
