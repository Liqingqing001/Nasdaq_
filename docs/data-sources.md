# 数据来源与限制

行情提供方：Yahoo Finance；获取工具：yfinance（非Yahoo官方SDK）。
工具说明：https://github.com/ranaroussi/yfinance
指数定义参考：https://indexes.nasdaq.com/Index/Overview/NDX

data/universe.csv是人工选择的10只开发样本及简化行业分类，不是任何指定日期的官方完整成分名单。全量快照尚未实现，不能据此重建纳斯达克100历史指数。

下载脚本记录UTC获取时间、请求范围、实际成功代码、失败代码、原始价格及复权口径、清洗数量和文件SHA256。下载结束日不包含在请求范围内。下载失败不得生成随机价格；完全失败保留旧缓存；部分失败在清单中披露。

原始OHLC用于K线；Adj Close用于收益、回撤和聚类。成交量按原始股数展示。滚动年化波动以252交易日为约定。月收益采用窗口内月末价格，首月缺少上月末基期，因此不计算。

缓存行情和环境密钥不纳入Git提交，使用者应遵守数据提供方条款，实际提交或公开数据前检查授权。测试中的人工价格路径仅用于验证公式，不会展示成实际行情。
