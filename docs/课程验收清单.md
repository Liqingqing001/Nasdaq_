# 数据可视化技术课程项目验收清单

课题：纳斯达克100成分股样本风险收益可视化与智能问数系统。
作者：李晴，202400702062，深圳技术大学数据科学与大数据技术，2024级。

| 要求 | 对应成果 |
| --- | --- |
| 需求分析及产品设计 | 作品文档第1节及docs/requirements.md |
| 数据采集与来源说明 | scripts/update_universe.py、scripts/download_data.py、data/manifest.json及来源说明 |
| 清洗与特征构造 | nasdaq/analytics.py、nasdaq/providers.py及样本指标表 |
| 机器学习模型 | 标准化加K-means，K值比较及聚类结果CSV |
| 至少10张图表 | 系统五页面的十余类图表，作品文档附录12张交互图表 |
| 金融方向自然语言驱动分析 | 中文问数、相对时间、相关性排名、趋势比较及CSV导出 |
| 大模型功能可选 | 未依赖大模型API，采用明确披露的规则解析 |
| 程序文件 | 程序目录，含本地行情缓存及PowerShell启动脚本 |
| 作品文档 | 自包含HTML，可离线打开 |
| 汇报PPT | 12页可编辑PPTX，含原生图表与讲稿备注 |
| 演示视频可选 | 未制作，提供现场演示流程 |

研究范围以63个完整历史证券样本收口，官方快照101个代码与实际行情覆盖71个代码分别披露。没有声称完整重建指数。
